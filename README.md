# RAG Pipeline with Hybrid Retrieval, Reranking and Citation Verification

A Retrieval-Augmented Generation (RAG) pipeline in Python that goes beyond the basic "embed, retrieve, generate" demo. It combines **hybrid search** (dense + BM25), **cross-encoder reranking**, **cited answer generation** with Gemini, and an **NLI-based verification layer** that checks whether each citation really supports the claim. An **evaluation harness** measures retrieval quality and hallucination rate.

## How it works

```
Documents (.txt / .pdf)
        │
        ▼
   1. Ingest        chunk text with overlap  ──►  data/chunks.json
        │
        ▼
   2. Retrieve      dense (MiniLM + Qdrant)  +  sparse (BM25)
                    fused with Reciprocal Rank Fusion (top 20)
        │
        ▼
   3. Rerank        cross-encoder (ms-marco-MiniLM) ──► top 5
        │
        ▼
   4. Generate      Gemini answers using ONLY the numbered sources,
                    with a [n] citation on each sentence
        │
        ▼
   5. Verify        NLI model (DeBERTa) checks each (claim, cited source)
                    ──► supported / not supported, hallucination rate
```

| Module | Role |
|--------|------|
| `src/ingest.py` | Loads `.txt` and `.pdf` files, splits them into overlapping word-based chunks, saves `data/chunks.json` |
| `src/retrieval.py` | `HybridRetriever`: BM25 + dense vectors in an on-disk Qdrant store, merged with RRF |
| `src/rerank.py` | `Reranker`: cross-encoder that re-scores the candidates for precision |
| `src/generate.py` | Builds the prompt, calls Gemini, and extracts `(claim, cited chunk)` pairs |
| `src/verify.py` | `CitationVerifier`: entailment check with `cross-encoder/nli-deberta-v3-base` |
| `src/pipeline.py` | `RAGPipeline`: wires everything together |
| `src/eval.py` | Precision@k, Recall@k, MRR and average hallucination rate on a labeled QA set |

## Why these choices

- **Hybrid search**: embeddings catch paraphrases, BM25 catches exact terms. Fusing both avoids the blind spot of each.
- **Retrieve broad, rerank narrow**: the fast retriever picks 20 candidates, then the slower but more accurate cross-encoder picks the best 5.
- **Citation verification**: LLMs can cite a source that sounds related but does not back up the claim. The NLI check flags those cases.

## Tech stack

- Python
- `sentence-transformers` (embeddings `all-MiniLM-L6-v2`, cross-encoders)
- `rank-bm25`
- Qdrant (local, on-disk mode, no server needed)
- Google Gemini API (`google-genai`)
- `pypdf`, `numpy`, `python-dotenv`

## Getting started

### Prerequisites

- Python 3.10+
- A free Gemini API key from [Google AI Studio](https://aistudio.google.com/apikey)

### Install

```bash
git clone https://github.com/Malekkk25/rag-pipeline-project.git
cd rag-pipeline-project
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
pip install qdrant-client
```

### Configure

```bash
cp .env.example .env
```

Then put your key in `.env`:

```
GEMINI_API_KEY=your-key-here
```

### Run

```bash
# 1. Put your .txt / .pdf files in data/raw/, then build the chunks
python -m src.ingest

# 2. Ask a question (edit the test query at the bottom of pipeline.py)
python -m src.pipeline

# 3. Evaluate on the labeled questions
python -m src.eval
```

You can also run each stage alone: `python -m src.retrieval`, `python -m src.rerank`, `python -m src.verify`.

The pipeline returns the answer, the retrieved chunks, a per-citation check (`supported`, `entailment_score`) and the overall `hallucination_rate`.

## Evaluation

`eval/qa_pairs.json` holds questions with the chunk ids that should be retrieved:

```json
{ "question": "What is Retrieval-Augmented Generation?",
  "relevant_chunk_ids": ["Test.txt::0"] }
```

`src/eval.py` reports:

| Metric | Meaning |
|--------|---------|
| Precision@k | share of retrieved chunks that are relevant |
| Recall@k | share of relevant chunks that were retrieved |
| MRR | 1 / rank of the first relevant chunk |
| Avg. hallucination rate | share of citations the NLI model marks unsupported |

For meaningful numbers, use a larger document collection and more questions than the small sample included here.
